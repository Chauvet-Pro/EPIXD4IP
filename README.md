# EPIX D4 IP

_Last Updated: 2026-04-01_

The Chauvet Professional Epix D4 IP is a four-port, IP65-rated power and processing module designed to simplify pixel mapping through the intuitive KLSTR system, with onboard GDTF support for seamless workflow integration.

Its rugged, modular design delivers full creative flexibility and industry-leading efficiency for lighting designers, system integrators, and rental applications in outdoor environments.

---

## Control Software

The Epix D4 IP supports firmware updates for feature enhancements and bug fixes. Firmware updates are performed using KLSTR software.

Detailed update instructions are available in the [User Manual](https://chauvetprofessional.com/product/epix-d4-ip/#downloads).
